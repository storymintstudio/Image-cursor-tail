# ✨ Cursor Image Trail

An interactive cursor effect where images follow your mouse movement with smooth fade, scale, and rotation animations.

### Features
- Dynamic image trail following the cursor
- Smooth fade-out and scaling effects
- Random image rotation
- Customizable trail length and image size
- Built with pure HTML, CSS & JavaScript

### Tech Stack
- HTML5
- CSS3
- Vanilla JavaScript
